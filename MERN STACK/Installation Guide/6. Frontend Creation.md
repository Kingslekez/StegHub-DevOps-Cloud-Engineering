Installing concurrently and nodemon as dev dependencies to run both backend and frontend concurrently, and editing package.json to add scripts.

```json
"scripts": {
  "start": "node index.js",
  "start-watch": "nodemon index.js",
  "dev": "concurrently \"npm run start-watch\" \"cd client && npm start\""
},
```
