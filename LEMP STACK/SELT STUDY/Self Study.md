## BASIC SQL SYNTAX AND MOST COMMONLY USED COMMANDS

Basic SQL (Structured Query Language) syntax is used to communicate with and manage relational databases. SQL statements are generally written using keywords such as <mark>SELECT, INSERT, UPDATE, and DELETE</mark>. The <mark>SELECT</mark> command is the most commonly used and retrieves data from one or more tables. A <mark>WHERE</mark> clause can be added to filter results based on specific conditions. The <mark>INSERT</mark> command adds new records to a table, while <mark>UPDATE</mark> modifies existing records. <mark>DELETE</mark> removes records that are no longer needed.

Database structures are created and managed using commands such as <mark>CREATE, ALTER, and DROP</mark>. <mark>CREATE</mark> is used to create databases, tables, and other objects. <mark>ALTER</mark> modifies an existing table structure, and <mark>DROP</mark> permanently removes database objects. SQL also supports sorting and grouping data using <mark>ORDER BY</mark> and <mark>GROUP BY</mark>. Aggregate functions such as <mark>COUNT(), SUM(), AVG(), MIN(), and MAX()</mark> are used to perform calculations on data.

Relationships between tables are handled through JOIN operations, allowing data from multiple tables to be combined in a single query. Common join types include <mark>INNER JOIN and LEFT JOIN</mark>. SQL keywords are not case-sensitive, but writing them in uppercase improves readability. Understanding these basic commands and concepts provides a strong foundation for querying, updating, and managing data efficiently in modern database systems.

## VIM and NANO
VIM and Nano are two popular text editors commonly used in Linux and Unix-based operating systems. Both editors allow users to create, edit, and manage text files directly from the command line, but they differ significantly in complexity and learning curve. Nano is designed to be simple and user-friendly, making it an excellent choice for beginners. It displays available keyboard shortcuts at the bottom of the screen, allowing users to quickly learn and perform common editing tasks. To open a file in Nano, the command nano filename is used. Important Nano commands include <mark>Ctrl + O</mark> to save a file, <mark>Ctrl + X</mark> to exit the editor, <mark>Ctrl + K</mark> to cut a line, <mark>Ctrl + U</mark> to paste text, and <mark>Ctrl + W</mark> to search within a file.

VIM, on the other hand, is a powerful and highly efficient editor favored by many system administrators and developers. It operates in different modes, including Normal mode for navigation and command execution, and Insert mode for entering text. Users press <mark>i</mark> to enter Insert mode and <mark>Esc</mark> to return to Normal mode. Common VIM commands include <mark>:w</mark> to save, <mark>:q</mark> to quit, <mark>:wq</mark> to save and quit, and <mark>:q!</mark> to quit without saving. Mastering both editors improves productivity and flexibility when working in command-line environments.
