This project successfully demonstrates the implementation of a full-stack MEAN (MongoDB, Express.js, AngularJS, Node.js) application for book management.   

We established a robust backend using Node.js and Express to create RESTful APIs, integrated MongoDB via Mongoose for data persistence with a well-defined book schema, and built a dynamic frontend with AngularJS for seamless CRUD operations. The application enables users to add, view, and delete books through an intuitive interface. 


Key challenges included syntax errors in schema definition and proper template literal usage for delete operations, which were systematically resolved. This project highlights MEAN stack's efficiency in building scalable, JavaScript-based web applications with unified language across all layers.
