MySQL Installation upon a web server up and running, the MySQL installation is needed to be able to store and manage data for your site in a relational database. MySQL is a popular relational database management system used within PHP environments.

Starting the interactive script helps with the following:  
•	Set or change the MySQL root password.  
•   Remove anonymous users.   
•	Disallow remote root login.   
•	Remove the test database.   
•	Reload privilege tables.
